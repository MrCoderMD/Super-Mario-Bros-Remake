## Assets
All game assets are available on the internet.

## Mario logic
I've programmed all of mario actions (moving, jumping etc) using a technique called **"Finite State Machine"** which makes programming logics very easier. Each action has its own state handler function like _Idle, Run, Jump, Crouch, Swim_.

## Level building
I've used the _**tilemaplayer**_ node to make levels in the game. Each level has its own tileset, each tileset has a unique ID for different blocks like _Used Block, Brick Block, Coin Block, etc._ These ID's help recognize Mario which blocks are being hit.

## Enemies
All classic Mario enemies are present in the game i.e. _Goomba, Koopa, Beetle, Lakitu, Hammerbro etc._ All enemies has different appearances according to the level. And all enemies has the exact same mechanic from the original game.
